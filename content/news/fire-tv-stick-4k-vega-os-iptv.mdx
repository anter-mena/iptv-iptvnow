Amazon's new **third-generation Fire TV Stick 4K**, announced on September 30, 2026 and now shipping in Canada, runs **Vega OS** instead of the Android-based Fire OS used by earlier sticks. Vega OS cannot install Android apps and only offers apps from the Amazon Appstore. That means the standard way to set up IPTV on a Fire TV (installing the Downloader app, then an IPTV player such as V12Mate) **does not work on the new stick**.

If you already own a Fire TV that streams IPTV NOW today, **nothing changes for you**. This affects new purchases only.

## What changed with the new Fire TV Stick 4K

The new stick launched at US$59.99 with a redesigned remote, Wi-Fi 6 and a slimmer design. It is not a straight upgrade, though:

- **Vega OS, not Fire OS.** Vega is Amazon's own Linux-based system. Android apps (APK files) cannot run on it, and there is no "install unknown apps" option for tools like Downloader.
- **Less memory.** It has 1 GB of RAM, half the memory of the 2nd-generation Fire TV Stick 4K it replaces.
- **No Dolby Vision.** It supports HDR10, HDR10+ and HLG, but drops Dolby Vision.
- **It replaces two Fire OS models.** The Fire TV Stick 4K Select and the Fire TV Stick 4K Plus are being phased out. Once current stock sells out, the **Fire TV Stick 4K Max** is described as the last Android-based stick in Amazon's line-up.

Vega OS does include a developer mode that installs apps from a computer over USB. It is built for app developers, needs a reboot each time and still cannot run Android apps, so it is not a way to install an IPTV player.

## How to check which one you have

On your Fire TV, go to **Settings → My Fire TV → About** and look at the software version:

- **Fire OS device:** the version is labelled **Fire OS**. You can follow our [Fire TV Stick setup guide](/installation-guides/fire-tv) as normal.
- **Vega OS device:** the version is listed as **OS** followed by a number starting with **1**. The Fire TV guide will not work, so use one of the options below.

On the 3rd-gen Fire TV Stick 4K there is also a physical clue: it is the only Fire TV with "4K" printed next to the HDMI plug.

## Buying a streaming device? Our recommendations

If you are shopping for a new device to watch IPTV NOW, choose one that can install IPTV players:

1. **Fire TV Stick 4K Max or Fire TV Cube.** Both run Fire OS and work with our step-by-step Fire TV guide. Check the model name carefully: "Fire TV Stick 4K" on its own is now the Vega OS model.
2. **An Android TV or Google TV device**, such as a Google TV Streamer, Nvidia Shield or onn. box. See our [Android TV guide](/installation-guides/android-tv).
3. **A dedicated IPTV box** such as a Formuler Z or BuzzTV, which have IPTV apps built in.
4. **The TV you already own.** Many Samsung, LG and Roku TVs can run the Hot Player app. See [all installation guides](/installation-guides).

If you have just bought a Vega OS stick and are still inside Amazon's return window, returning it for a Fire OS model is the simplest fix.

## Will Amazon convert existing Fire TVs to Vega OS?

No. When Amazon launched Vega OS in 2025, it said existing Fire OS devices would keep Fire OS and continue to receive updates, and that Fire OS "is not going away." Fire TV smart TVs and the Fire TV Stick 4K Max also continue to run Fire OS.

We will update this article if Amazon changes which devices run Vega OS, or if IPTV players become available for it. If you are not sure whether your device is supported, [contact our support team](/contact) with the model name and software version and we will tell you the best way to get set up.
